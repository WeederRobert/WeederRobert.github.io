关于

这里记录工程实践、工具踩坑和读书笔记。写下来的目的很简单：半年后自己还能看懂当时为什么这么决定。

这个站点怎么做的

  • 纯静态 HTML / CSS / JavaScript，没有构建步骤，也没有任何第三方依赖。
  • 文章清单由 posts.json 维护，首页用它渲染列表。
  • 部署走 GitHub Actions：推送到 main 就发布到 GitHub Pages。
  • 深色 / 浅色跟随系统，可手动切换并记住选择（存在本地浏览器里）。

为什么不用框架

博客的复杂度在「持续写」而不在「渲染」。免构建意味着十年后拉下仓库，双击就能改，不依赖某个版本的 Node。
