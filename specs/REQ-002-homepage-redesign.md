# REQ-002 首页改版：仿 xxynet/HomePage 的个人主页版式

- 状态：`approved`（autopilot 模式按本文件假设推进）
- 项目：`MyBlog/`
- 提出：2026-11-24
- 关联：[REQ-001](REQ-001-github-io-blog.md) · 版式参考 <https://github.com/xxynet/HomePage>

## 1. 需求

把「文章列表 + 简单页头」的首页改成个人主页版式：左侧个人卡片（标识 / 标签 / 时间线），右侧大幅问候语、社交入口、文章与站点卡片；深浅色切换带过渡。

不要：复制参考站的代码或图片（该仓库没有 LICENSE，默认版权保留）；不引入任何第三方依赖或 CDN。

## 2. 现状与事实

- 参考仓库根目录只有 `index.html`、`static/`、两张截图，**无 LICENSE 文件**，因此只能仿「版式与交互形态」，不能复用其代码、图片、音效。
- 已下载其 `DarkMode.png` 截图作为视觉参考（未放进本站）。
- 现站是无构建静态页：`index.html` + `assets/style.css` + `assets/app.js`，文章列表由 `posts.json` 渲染。

## 3. 验收标准

| # | 可观察结果 | 验证方式 |
| --- | --- | --- |
| AC-1 | 首页三块齐全：左栏个人卡（标识 / 标签 / 时间线）、右栏问候语与简介、文章卡片区 | 浏览器 1280px |
| AC-2 | 文章卡片仍由 `posts.json` 渲染，条数与清单一致 | 浏览器 + 静态校验 |
| AC-3 | ≤900px 单列堆叠；375px 无横向滚动 | 浏览器 375px |
| AC-4 | 深浅色切换有过渡动画，刷新后保持 | 浏览器 |
| AC-5 | 无第三方请求（无 CDN / 外部字体 / 图标库 / 外链图片） | 静态扫描 |
| AC-6 | 站内链接 0 死链，文件无 BOM | 脚本 |
| AC-7 | 文章页 / 关于 / 404 版式不破 | 浏览器 |
| AC-8 | 未使用参考站代码与图片，README 注明灵感来源 | 人工核对 |

## 5. 复用基线

- 复用（禁止重写）：`posts.json` 清单、`escapeHtml` / `formatDate` / `renderPosts`、主题键 `blog-theme`、`data-post-list` / `data-theme-toggle` / `[data-year]` 契约、`scripts/set_site.py`。
- 新增可复用件：
  - `assets/app.js` 的 `[data-local-time]` 填充（浏览器本地时间 + 时区名）。
  - `.chip` / `.link-card` / `.timeline` / `.profile` 组件样式，供 about 页复用。

## 6. 决策与取舍

| 决策 | 备选方案 | 为什么选这个 |
| --- | --- | --- |
| 仿版式、代码自研 | Fork 参考仓库改内容 | 该仓库无许可证，整段复用属侵权；其内容（Caleb XXY）需整体替换，改造量也接近重写 |
| 保持无构建 | 引入 Vue / Vite | 与 REQ-001 的「免工具链、可审计」一致 |
| 图标用内联 SVG / emoji | 图标字体 CDN | 不产生第三方请求 |
| 文章仍走 `posts.json` | 写死卡片 | 单一事实源，避免与 RSS / sitemap 脱节 |
| 头像用文字缩写 + 渐变 | 用参考站头像 / 图库图片 | 规避素材版权 |

## 7. 不做的事

- 评论、搜索、多页导航、动画库、音效。
- 不监听系统主题变化（保留首次判定 + 手动覆盖即可）。

## 8. 口径与边界

- 参考站仅作版式参考，代码与素材均为本仓库原创；README 与本节记录来源。
- 本地时间由浏览器推导，不做服务端时间。
- 深色默认跟随系统首次判定，之后以 `localStorage` 为准。
