## 做了什么

- 新增全站共用的 `.topbar`：左侧站点名，右侧 文章 / 关于 / RSS / GitHub + 主题按钮，当前页用 `aria-current="page"` 高亮。

- 删除旧的 `.site-header` / `.site-nav` 与首页 `.actions` 里的「关于」「主题按钮」，全站只保留一个 `[data-theme-toggle]`。

## 新增 / 改动的可复用件

- `.topbar` + `.topbar-inner` + `.nav`：四个页面共用同一份结构与样式。
- CSS 变量 `--topbar-h`（56px）与 `--topbar-bg`（深浅色各一份），改高度或底色只动一处。

## 决策与理由

- 选 `position: sticky` 而不是 `fixed`：不脱离文档流，无需给内容补 `padding-top`，也不会在移动端键盘弹出时错位。
- 导航放在 `<body>` 顶层、内层限宽：这样滚动容器是视口，才能全宽贴顶。
- 移除首页 `.actions` 里的重复入口：导航已提供，重复只会让首屏更吵。

## 遗留与限制

- 推送时 `github.com` 的 DNS 被污染（解析到 `57.155.223.240`），`git push` 无法完成；改用 GitHub API 创建 blob / tree / commit 并更新 `refs/heads/main`。线上 tree 与本地一致，但 **commit 对象不同**（远端 `b8877bf`，本地 `6fc4998`）。
- 网络恢复后需执行一次 `git fetch origin && git reset --hard origin/main`，让本地与远端对齐；之后再正常 `git push`。
- 无汉堡菜单：4 个入口在 375px 下仍可横排，暂不需要抽屉。

## 后续

网络恢复后同步本地；如后续导航项变多（>6），再考虑移动端折叠。
